## 0. 한 줄 요약

대치온은 **대치동 단과·재종 강사 1인 브랜드를 위한 멀티테넌트 SaaS LMS**다.
강사가 신청하면 `{내도메인}.daechion.com` 사이트가 로고·테마컬러까지 입혀서 발급되고,
그 안에 **관리자(CRM) / 학생·학부모 포털(SP) / 공개 게시판 / 알림톡 매직링크** 4개 앱이 들어있다.
핵심 차별점은 ① OMR 자동채점+문항별 통계, ② 성적 미달 시 자동으로 클리닉 예약이 걸리는 연동,
③ 카카오 알림톡 40여 종 자동 발송, ④ 조교 출퇴근·급여 정산까지 포함한 학원 운영 관리.

## 1. 사이트 구조 (전체 지도)

```
daechion.com                     ← 마케팅 랜딩 (Next.js, 페이지 2개뿐)
├─ /                             랜딩 (히어로/페인포인트/FAQ/소식/후기/요금제)
└─ /submit/                      가입 신청 3단계 위저드 (robots.txt에서 Disallow)

api.daechion.com                 ← 백엔드 API (AWS ap-northeast-2, 3.34.217.237)

{brand}.daechion.com             ← 실제 LMS 본체 (테넌트별 사이트)
  예: soohun / kimjieun / daechanedu ... (구글 색인 확인됨)
```

sitemap.xml에는 `/` 하나만 등록되어 있고, 랜딩의 모든 CTA는 `/submit/`으로 간다.
**즉 "기능이 있는 페이지"는 전부 테넌트 서브도메인 쪽에 있다.**

### 기술 스택 (관측된 것)

| 영역 | 스택 |
|---|---|
| 랜딩 | Next.js (App Router, RSC), Tailwind, shadcn/radix, Firebase Firestore + Storage(로고 업로드), 토스페이먼츠 |
| LMS 본체 | **Vite + React SPA** (Next 아님), React Router, **MUI**, PWA(manifest/maskable icon) |
| 실시간 | WebSocket + **STOMP** (동시 채점 동기화용으로 추정) |
| 영상 | 자체 플레이어(video-vendor), S3 업로드 + 서버 인코딩, 업로드 6단계 추적 |
| 모니터링 | Sentry + 자체 error-logger 백엔드 엔드포인트 |
| 앱 | React Native 웹뷰 래핑 (`RNPostMessageUtil`, `useCheckAppWebView`) |
| 기타 | GraphQL은 일부만(단어장·종이성적표), 나머지는 REST |

테넌트 HTML에는 `window.__TENANT__` 전역이 인라인으로 박혀 있다 — 빌드는 하나, 셸만 테넌트별 주입:

  COLOR_SCHEME_50 ... COLOR_SCHEME_900,   // 팔레트 10단계

### FAQ 전문 (제품 스펙이 사실상 여기 다 있음)

**[성적/채점]**

- **학생 성적표에 어떤 정보가?** 점수대별 인원, 상위 10% 평균, 최고점수, 문항별 통계. 차시별 변화를 보는 **누적성적표**. 현장/온라인 응시자 **분리 또는 통합** 기준 통계. 학생이 제출해 채점받은 **OMR·시험지 스캔본** 열람.
- **배점과 답안이 복잡한데?** 선택형+서술형 모두 지원. **소수점 배점**, **복수정답**, 문항오류 시 **예외답안** 지원. 성적 공개 후 답안 변경 시 학생 성적표에 **실시간 반영**.
- **조교 여러명 동시 채점?** 동시 접속 시 **즉시 동기화**. 선택형은 OMR 자동채점, 서술형만 수동. 서술형도 OMR 점수입력란에 조교가 적어 스캔·업로드하면 **자동 입력**.
- **선택형 100문항 OMR?** 선생님별 맞춤 선택형+서술형 OMR. 선택형만/서술형만도 가능(사전 미팅에서 논의). 내신·단과·재종 양식 대응.
- **재시험 엑셀 정리?** **여러 차례** 재시험 점수·상태 기록, 전부 성적표 반영. 재시험은 현장/온라인 모두. 미통과인데 재시험 미응시 → 학생 쪽 **'미완료 할 일'** 표기 + 클리닉 예약/온라인 제출 **재촉 알림톡**.

**[온라인 관리]**

- **영상 수강생 활용?** 자체 플레이어(**배속·인덱스·이어보기**). 사이트 내 과제·시험 온라인 제출 및 채점, 성적 분리/통합 조회. **차시별 자료실 + 강의별 자료실**. **질의응답 게시판**.
- **자료·영상 유출?** **3단계 워터마크**(노출 강도 조절), 자체 플레이어 + 영상 워터마크. **자료 다운로드 횟수·영상 시청시간 기반 이상 이용패턴 모니터링**.
- **영상 저장 비용?** 추가 과금 없이 기본 제공.

**[알림/소통]**

- **성적 발송 비용 절감?** SMS 대신 **카카오 알림톡 연동**. 성적 공개 시 발송 없이도 학생·학부모가 사이트에서 확인. 점수/등급/등수/평균/피드백 **데이터 삽입**해 알림톡 발송.
- **"등원했나요?" 연락 폭주** 클리닉 전 **리마인더**, **등원/하원 알림톡**, 미등원 시 **재촉 알림톡**, 하원 시 **피드백 작성 후 발송**.
- **연락 채널 분산** 사이트에서 성적·정정사항·과제 공지. 질의응답 글 작성 → **담당 조교에게 알림톡**, 답변 완료 → **학생에게 알림톡**.

**[운영 관리]**

- **클리닉 예약** 클리닉·상담 예약 모두 사이트 내. 시간/장소/**강의별 여석 분배**/예약 오픈·종료 시간 설정. 조교 대리예약 + 학생·학부모 직접예약. **설문조사·실시간 신청·학교성적 수집** 기능.
- **조교 관리** 관리자에서 **출근 유형(시급제)** 생성 → 조교별 설정, 조교는 로그인 시 출근 유형 선택. **출퇴근 기록 기반 급여 산정 + 개별 비용 청구**. **월급제** 설정. 전체 비용 통계.
- **학생 기록** 성적 추이·상태, 학교 성적, **개별 메모, 상담일지, 클리닉 기록**. **태그** 부여.

## 3. `/submit/` — 가입 신청 플로우

3단계 위저드: **① 요금제 → ② 정보입력 → ③ 결제**

**② 정보입력 필드**
- 표시될 이름 (ex) 홍길동 수학) / 전화번호 / 담당 과목 / 캐치프레이즈
- **도메인 이름** — `gildongmath` + `.daechion.com` (영문 소문자·숫자·하이픈만). 툴팁: *"학생 관리 및 성적표 열람 등 모든 업무가 이루어지는 선생님의 사이트 주소입니다."*
- **메인 색상** (컬러피커) / **로고 업로드** (드래그) / 추천인
- **미팅 신청** — `1:1 안내가 필요해요 (20~30분)` → `원격으로` / `대면으로`("대치동 출발 기준 1시간 내외로 찾아뵙습니다")

**③ 결제** — 토스페이먼츠. 카드 결제 / 계좌 이체. 현금영수증(휴대폰번호) 또는 세금계산서(사업자등록번호). "입금을 완료했어요" 버튼.

신청 데이터는 Firestore에 한글 키로 저장(`이름/전화번호/과목/캐치프레이즈/도메인/메인색상/요금제/결제금액/미팅필요여부/미팅방식/로고파일명/추천인/상태/신청일시/customerKey/tenantId`).

## 6. 기능 인벤토리 (메뉴별)

### 6-1. 강의 / 차시
- 강의 CRUD, 요일·시간 반복 일정, 별명·색상, 담당 선생님·조교 배정
- **지난 강의 설정 복사로 새 시즌 시작** (텍스트 치환: "2025"→"2026", 날짜 일괄 이동)
- 차시 카드 뷰, 새 차시 추가, 종강 처리, 강의 순서 드래그
- 수강생: 직전 차시/특정 차시/엑셀에서 불러오기, 일괄 추가, **반 이동**(성적·권한 이관 포함)
- 출결: 상태 일괄 변경, 출결 메모, **출결 잠금**(다음 차시까지 상태 유지)
- 차시 탭: 정보 / 출석 / 성적 / 시험 / 과제 / 영상 / 자료 / 주간 콘텐츠 / 현장 자료
- 강의 게시판, 강의 자료실, **디데이 설정**
- 키보드 단축키로 강의·차시 빠른 이동(초성 검색 지원)

### 6-2. 성적 · OMR (핵심)
- **OMR 답안지 자동 생성**: 2~5지선다 / abcde / OX, 수학 단답형, 서술형 배점란, 선택형·서술형 번호 혼합, 16색 용지, 좌측상단 문구·하단우측 텍스트, 시험코드, 학생/부모 전화번호란
- 기본 제공 양식 외 **강대K 전용**(수학/과학/K+과학/영어/국어), 뉴텝스, 수능형(국어/수학/영어/탐구/한국사/제2외국어)
- **OMR 스캔 업로드 → 자동 인식 → 학생 매칭**(성공 / 매칭 필요), 매칭 실패건 수동 지정("주인을 찾아줬어요"), 선택과목 자동 분류
- OX 채점, 이미지 자동 인식, 자동 배점, 맞은 개수 채점
- 성적 엑셀 일괄 업로드(양식 제공), 수동 입력, 피드백 입력
- **오답노트 자동 제작**: 틀린 문제 + 해설 + 동형 문제 + 동형 해설 블럭 조합, 표지/후면 이미지, **중철 제본용 책자 인쇄 모드**(빈 페이지 자동 삽입), PDF 일괄 인쇄 프로그램 제공
- **빌보드**(성적 우수자 게시): 상위 N명, 이름 마스킹, 이벤트 대상 지정(과제 전체 해결 + 시험 상위 20%/30%)
- 재시험 1차/2차/3차 응시 자동 생성 규칙, 커트라인 미달 처리 정책
- **종이 성적표 빌더**(`report-builder`): 요소 크기·위치 자유 배치, 데이터 자동 채움, **QR로 모바일 성적표 이동**
- 문항 **유형별 분석**: 유형 자유 등록, 유형별 석차·평균·상위 30% 평균, 그래프/표, (예정) 학생별 취약 유형 분석

### 6-3. 클리닉 / 상담
- 예약 관리(일정·장소·강의별 여석 쿼터·예약 오픈/종료 시각), 학생 직접예약 + 조교 대리예약
- 세션 단위 관리: 등원 / 재촉 / 하원 처리(알림톡 동반 or 알림 없이), 일괄 등원·재촉·하원
- 참여자 **세션 이동**, 세션에서 제거, 담당 조교 자동 추천(오늘 담당 여부 + 과거 담당 이력 4분면)
- 일자별 할 일 관리, 관리 대상자(클리닉 미예약 / 온라인 제출 필요), 채점 필요 목록
- 클리닉 메모, 성적 이력 인라인 확인, 엑셀 다운로드
- 상담: 대면/유선, 상담일지, 리마인더, 미등원 재예약 필요 처리

### 6-4. 학생 관리

- 학생 상세 모달 탭: **수강 이력 / 클리닉 및 상담 이력 / 질문 이력 / 성적 이력 / 학교 성적**
- 메모 + 상담일지(고정, 검색, 작성자·일시), 전체 메모 모아보기
- 학교 성적 개별·일괄 입력(엑셀 양식), 일괄 수정/삭제
- 비밀번호 일괄 변경(학생/부모/둘 다), 엑셀로 학생 일괄 선택
- **접속 QR 코드 생성**(모양 원형/네모, 색상, 로고 삽입 — 교재·유인물 삽입용)

### 6-5. 설문 / 신청

## 10. 세정 LMS 관점에서의 시사점

**구조적으로 반드시 따라가야 할 것**
1. **멀티테넌트를 처음부터 전제**로 설계 — 서브도메인 + 브랜드 팔레트 10단계 + 로고. 대치온은 빌드 하나에 셸 주입 방식이라 배포가 단순하다.
2. **역할 4종**(관리자/선생님 · 조교 · 학생 · 학부모)이 아니라 **앱 4종**(CRM · SP · Board · Link)으로 나눠야 화면 설계가 꼬이지 않는다.
3. **매직링크(`/link/:msgUuid`)** — 로그인 없이 알림톡에서 바로 등원 처리/성적 확인. 학부모 이탈률을 결정하는 부분.
4. **설정을 코드가 아니라 테넌트 플래그로** — 위 7장 표가 사실상 요구사항 협상 비용을 없애는 장치다.

**기능 차별점의 원천 (베끼기 어려운 순)**
- OMR 자동생성 + 스캔 인식 + 학생 자동 매칭 (진입장벽 최상)
- 성적 커트라인 미달 → 재시험 생성 → 미응시 시 '미완료 할 일' → 클리닉 예약 재촉 알림톡, 이 **자동 연쇄**
- 조교 출퇴근·급여 정산까지 포함한 운영 관리 (경쟁 LMS가 잘 안 건드리는 영역)
- 알림톡 템플릿 40종 + 데이터 삽입 변수

**과금 모델**: 활성 학생 수 기준 3구간, 초과 시 관리자 화면에서 업그레이드 강제. 영상 저장·알림톡·OMR은 무제한(원가 흡수) → 학생 수 하나로만 과금해 영업 대화가 단순해진다.
